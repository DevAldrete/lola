# Logistics Oriented Language Assistant

A task manager app for logistic usage

How the structures fit together:
Priority queue: urgent deliveries.
Binary tree: distribution centers or vehicles.
HashMap: quick search for packages by waybill.
Sorting: routes, delivery dates, costs.
Search: package tracking.
Recursion: calculation of cumulative times on routes.
Divide and conquer: partitioning geographic areas to assign deliveries.
Graphs: cities and transportation routes.
